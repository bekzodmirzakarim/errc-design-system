Medical monitoring UI for neuroradiologists tracking stroke (ОНМК) patients in real time

Система мониторинга инсульта

ЕРРЦ — это корпоративная система для невролучевиков по мониторингу пациентов с инсультом (ОНМК) в реальном времени. Система включает дизайн-систему с полным набором компонентов, токенов цвета и типографики, а также два интерактивных UI-кита: доску мониторинга для ридинг-центра и операционный экран для стены.

Стек: React (Babel in-browser), CSS variables, Lucide icons, Inter + JetBrains Mono

📋 Design System

Полный набор токенов дизайна, цветовой палитры, типографики и базовых компонентов. Все стили определены как CSS-переменные для максимальной гибкости.

🏥 Мониторинг ОНМК

Интерактивная 5-колонная доска для отслеживания пациентов через фазы (Ожидание → Готово). Живые таймеры door-to-needle, фильтры по статусу, детальный drawer с витальными показателями.

📺 Операционный экран

1920×1080 wall display для операционной: карта Узбекистана с регионами, KPI, лента пациентов, панель экспертов, AI Stroke очередь. Auto-refresh каждые 5 секунд.
